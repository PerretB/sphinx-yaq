# Changelog

No releases yet. The first release is in preparation.

- Added English and French interface catalogs, with project, document, and quiz
  language selection. YAQ now follows Sphinx's `language` by default; use
  `yaq_language = "en"` to preserve English controls in a French project.
- Localized accessibility labels, feedback, errors, and pluralized status messages.
  Learner-facing math errors no longer append untranslated library exception text.
  UI language changes preserve compatible saved progress.
