# Documentation

For the current package, use the [authoring and usage guide](usage_guide.md),
[legacy migration guide](migrating_from_legacy.md),
[release readiness](release_readiness.md), and
[migration status](migration_status.md). The demo in `examples/demo` is an
installed-extension example.

`technical_description.md`, `python_extension.md`, `javascript_library.md`,
`code_review.md`, `dependency_inventory.md`, and
`prioritized_improvements.md` record the legacy implementation and the
original migration analysis. They mention deleted Firebase, Watch.JS, and
copied-extension paths and are historical references, not instructions for
the current package. The batch contracts in `migration_batches/` record the
planned scope and acceptance criteria.
