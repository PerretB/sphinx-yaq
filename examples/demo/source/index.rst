Exemple de cours avec SphinxDoc
###############################

Ce projet illustre rapidement comment créer un cours avec SphinxDoc et comment intégrer des exercices interactifs dans ce cours.

Ressources utiles:

	* `Restructured Text <https://www.sphinx-doc.org/en/master/usage/restructuredtext/index.html>`_ : documentation sur le langage de balisage Restructured Text (rst) utilisé par SphinxDoc
	* `Restructured Text Cheat Sheet <https://github.com/ralsina/rst-cheatsheet/blob/master/rst-cheatsheet.rst>`_ : l'essentiel du format rst à un endroit.
